# Week Progress (週進度追蹤)

[![Code with Gemini](https://img.shields.io/badge/Code%20with-Gemini%203%20Flash%20Preview-blue?style=for-the-badge&logo=google-gemini)](https://gemini.google.com/)

一個輕量級的網頁工具，用於視覺化和追蹤每週進度。

## 🚀 功能特點
- **視覺化進度追蹤**：輕鬆查看一週內的進度狀況。
- **互動式介面**：簡單直觀的介面，方便快速更新。
- **Firebase 支援**：已預先配置 Firebase Hosting 部署設定。

## 🛠 技術棧
- HTML / CSS / JavaScript
- [Firebase Hosting](https://firebase.google.com/docs/hosting)

## 📦 開始使用

### 本地開發
只需在瀏覽器中開啟 `index.html` 即可。

### 部署
本專案已配置 Firebase Hosting。部署步驟如下：
1. 安裝 Firebase CLI：`npm install -g firebase-tools`
2. 登入：`firebase login`
3. 部署：`firebase deploy`
