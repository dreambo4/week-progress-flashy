> **讓小恐龍陪你一起撐到下班。**

一個給上班族的療癒小角落。在漫長的工時裡，陪你喝口水、看看天氣、餵餵桌上那隻發呆的小恐龍——溫柔地陪你數著下班的距離。

## 🦖 它陪你做什麼

- **養一隻小恐龍**：餵食、拍拍，讓牠在你工作的時候陪在身邊。
- **下班倒數**：用進度條看著時間一點點走完，下班其實沒那麼遠。
- **動態天氣背景**：依你所在地的真實天氣與日出日落，畫面隨之變化。
- **暖心語錄**：時不時跳出一句話，給疲憊的你一點力氣。
- **貼心提醒**：整點喝水、下班提醒、進度達標、天氣變化，都可自由開關。
- **八種主題**：霓虹之夜、柔和流動、駭客終端、日落地平線、深邃森林、紫幻午夜、極簡純白、烈焰熔岩，挑一個你今天的心情。

## 🛠 技術棧

- HTML / CSS / JavaScript（純前端，無需後端）
- [SunCalc](https://github.com/mourner/suncalc) — 計算日出日落
- [canvas-confetti](https://github.com/catdad/canvas-confetti) — 慶祝下班的小彩帶
- [Firebase Hosting](https://firebase.google.com/docs/hosting) — 部署

## 📦 開始使用

### 本地開發

在瀏覽器中開啟 `index.html` 即可，第一次使用記得到右上角 ⚙️ 設定你的上下班時間與作息。

### 部署

本專案已配置 Firebase Hosting：

1. 安裝 Firebase CLI：`npm install -g firebase-tools`
2. 登入：`firebase login`
3. 部署：`firebase deploy`
